# AI-Slop Pattern Reference

Patterns are prompts for investigation, not automatic violations. Report a pattern only when it weakens product communication, usability, credibility, or intentionality.

## Copy Clusters

- Category-free claims: “Transform how you work” without naming the work or mechanism
- Inflated verbs: revolutionize, supercharge, unlock, elevate, reimagine
- Empty adjective stacks: seamless, powerful, intelligent, intuitive, next-generation
- Symmetrical fragments: “Faster. Smarter. Better.”
- Repeated paraphrases of one benefit across several sections
- Features expressed only as outcomes, or outcomes expressed only as features
- Unsupported absolutes, metrics, customer counts, testimonials, or security claims
- Headings that introduce no new information
- Generic CTA labels where the actual next step is known
- Sudden tone changes between polished marketing copy and functional interface text

## Visual Clusters

- Gradient headline plus glow plus floating cards used without product meaning
- Every idea placed in an equally weighted rounded card
- Bento grids whose grouping reflects available space rather than user decisions
- Arbitrary icon sets, emoji, or illustrations with inconsistent semantics
- Browser frames containing implausible or decorative product UI
- Repeated alternating text-and-image sections with no narrative progression
- Excessive badges, pills, chips, and eyebrow labels
- Large empty areas created for spectacle rather than hierarchy
- Multiple unrelated decorative motifs
- Motion applied uniformly rather than to explain state or causality

## UX Clusters

- Several primary-looking CTAs with different destinations
- Navigation organized around internal feature names rather than visitor questions
- Long landing pages that delay concrete product explanation
- Pricing, onboarding, or contact motion inconsistent with the CTA promise
- Hover-only information, inaccessible carousels, or animated content without controls
- Mobile layouts that simply stack desktop cards into a very long page
- Missing focus, error, loading, empty, success, or disabled states

## Credibility Clusters

- Invented-looking dashboards, metrics, notifications, or user activity
- Logos, testimonials, awards, ratings, or compliance marks without context
- “Enterprise-grade” positioning without security, reliability, or support details
- Product screenshots that contradict repository behavior or visible live functionality
- Broad claims that exceed the narrow product demonstrated
- Team, contact, privacy, or legal information missing where buyer risk makes it important

## Evidence Standard

For each reported pattern, capture the exact phrase, component, route, state, or responsive behavior. Explain which product-specific information or user need it displaces. Prefer “This hero is interchangeable because…” over “This looks like AI.”
