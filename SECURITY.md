# Security policy

Please do not report private URLs, credentials, customer data, or other sensitive site
content in a public issue.

For a security concern in the repository or plugin packaging, contact the maintainers
privately through the security contact configured for the eventual public repository.
Until that contact is published, open a minimal issue asking for a private channel and do
not include sensitive details.

Antislop is an audit skill. It does not claim that a website, product, business, or legal
claim is safe, compliant, or production-ready.
